# Nmap-Scanning-Techniques
with hands-on experience in using Nmap to explore different types of scanning techniques in penetration testing. 
# Pre-Requisites:
•	Install at least two virtual machines (e.g., Kali Linux, Ubuntu, or Windows).
•	Configure all VMs to be on the same virtual network using "Bridged Mode."
•	Ensure VMs have IP addresses in the same subnet (e.g., 192.168.1.0/24)
